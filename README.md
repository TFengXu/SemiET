# SemiET

Official repository for **SemiET: Semi-Supervised Fundus Enhancement with Efficient Transformers**.

## Code and model

The source package is now browsable in [`code/`](code/); the original archive is also available [here](https://github.com/TFengXu/SemiET/raw/refs/heads/main/SemiET_initial_source_release.zip). The inference checkpoint, configuration, and metadata are available in the [v0.1.0-alpha.1 pre-release](https://github.com/TFengXu/SemiET/releases/tag/v0.1.0-alpha.1). Some components needed to reproduce every experiment, including third-party downstream toolkits, are not redistributed in this repository; see the source documentation for details.
