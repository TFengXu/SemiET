# SemiET

Official repository for **SemiET: Semi-Supervised Fundus Enhancement with Efficient Transformers**.

## Staged code and model release

The public release is being made progressively. The initial source bundle is available [here](https://github.com/TFengXu/SemiET/raw/refs/heads/main/SemiET_initial_source_release.zip), and the current inference checkpoint, configuration, and metadata are available in the [v0.1.0-alpha.1 pre-release](https://github.com/TFengXu/SemiET/releases/tag/v0.1.0-alpha.1). Additional components and reproducibility materials will be added after verification. Some components needed to reproduce every experiment, including third-party downstream toolkits, are not included in this initial release.
